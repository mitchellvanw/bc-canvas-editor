foreignObject + self-painting layer + downscaled <img>

One SVG containing a <foreignObject> with four lines of XHTML text: a plain control, a position: relative line, an opacity: 0.6 line, and a line whose bullet carries a CSS transform. The same data: URI is shown twice below — at natural size (400px) and at half size (200px).

Expected: the half-size image is the natural-size image scaled uniformly (this is what Chrome and Firefox do).
Actual (WebKit/Safari): at half size, the three lines that create a self-painting layer (positioned box, opacity < 1, transform) paint at full, unscaled size — overflowing their lines and the image box — while the control line scales correctly. At natural size everything is correct.
