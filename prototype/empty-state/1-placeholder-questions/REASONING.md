# Variant 1 — Placeholder questions

**Bet:** the form itself is the teacher — no hint layer at all. Every empty
field's italic placeholder asks the section's question ("What does this context
exist to do? A few sentences in business language."), and while a section is
empty its ghost add carries the question too ("+ collaborator — who sends this
context commands, queries or events?"). The blank sheet reads as a
questionnaire; the filled sheet is untouched.

- **Disappearance:** instant and granular. Typing kills a placeholder; the first
  item snaps the ghost back to its terse label ("+ collaborator").
- **Seeding:** none — the canvas starts byte-empty.
- **Copy budget:** one clause per section, living exactly where the user acts.
- **Gains:** quietest possible; zero new surfaces; nothing to dismiss; teaching
  and affordance are the same element, so discoverability rides for free.
- **Sacrifices:** teaching capacity is a single clause; the method's "why"
  (lanes, message types, context-mapping) goes unexplained; once one item
  exists the section never teaches again.
