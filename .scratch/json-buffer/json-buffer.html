The JSON box: what can disagree with the canvas, and for how long

The JSON view shows a canvas as the file it exports to, and lets you edit that text and press Apply. That makes something this editor has never had: a second piece of text that is allowed to disagree with the canvas, for as long as you like. This page is the model behind that — the real parser, the real serializer, a stand-in canvas — so the awkward moments can be pressed rather than argued about. Nothing here is the app.
