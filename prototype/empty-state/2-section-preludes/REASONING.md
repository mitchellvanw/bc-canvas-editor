# Variant 2 — Section preludes

**Bet:** the sheet annotates itself — each empty section opens with a one-to-two
sentence serif-italic hint between label and body, the ddd-crew helper question
rewritten in house voice ("Who asks this context to act, and how? Each
collaborator gets a lane with the commands, queries and events it sends.").
Field placeholders shrink to "…" so the prelude does all the teaching and
nothing is said twice.

- **Disappearance:** per section, at the first *committed* content (field blur /
  structural add) — and the hint returns if the section is emptied again, so
  teaching is state-driven, not first-run-driven.
- **Seeding:** none.
- **Copy budget:** full sentences — the only variant that can actually explain
  the method (lanes, precise-inside-the-boundary language, falsifiable
  assumptions).
- **Gains:** genuine teaching; hints sit in the reading position (under the
  label) rather than in the answer position, so empty fields don't masquerade
  as filled.
- **Sacrifices:** nine italic paragraphs make the blank canvas wordy — it opens
  as an essay about canvases and only becomes a canvas as you fill it; hint
  reappearing-on-empty may surprise.
