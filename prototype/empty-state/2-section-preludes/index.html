Bounded Context Canvas · V5

Description

What does this context exist to do — which behaviors and data does it own? Business language, not implementation.

Domain roles

How does this context behave — running a workflow, fronting an external system, recording what happened? Pick the traits that fit.

    Inbound communication

    Who asks this context to act, and how? Each collaborator gets a lane with the commands, queries and events it sends.

    Ubiquitous language

    Which terms carry a precise meaning inside this boundary? Define them as used here — the same word can mean something else next door.

    Business decisions

    Which rules and policies does this context enforce? The decisions that shape its behavior.

      Outbound communication

      Where does this context's output go? Each collaborator gets a lane with the messages it receives from here.

      Assumptions

      What are you taking to be true — about the business, the data, other contexts — that would change this design if false?

        Verification metrics

        How would you check this boundary is right? Measurements that would confirm the design, or send you back to it.

          Open questions

          What don't you know yet? Open questions mark where the model is still soft.
